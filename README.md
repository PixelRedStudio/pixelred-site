# PixelRed Studio — portfolio

Site statique officiel du studio et vitrine de **TapSafe** et **Flickerun**.

## Langues

Le sélecteur propose les dix langues du site : français, anglais, allemand, espagnol, italien, portugais, russe, japonais, coréen et chinois. Au premier accès, la langue du navigateur est choisie automatiquement; la préférence est ensuite conservée dans le navigateur.

## Contenu

- `index.html`, `style.css`, `script.js` : portfolio responsive et contenus localisés.
- `site_assets/` : images optimisées du portfolio et image Open Graph.
- `privacy*.html`, `privacy-flickerun.html`, `mentions-legales.html` : pages de confidentialité et mentions légales.
- `CNAME` : domaine personnalisé `pixelredstudio.com`.

## Publication

Le site est hébergé avec GitHub Pages depuis ce dépôt. Les changements publiés sur la branche configurée sont servis sous `https://pixelredstudio.com/`. Pour annuler une mise à jour, revenir au commit précédent et le pousser à nouveau.
